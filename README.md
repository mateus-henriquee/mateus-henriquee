## 🌟 Projetos em destaque  

Aqui estão alguns projetos que tenho orgulho de compartilhar:

1. **[DataMind 🏥](https://github.com/mateus-henriquee/ORACLExDATASUS_challenge-FIAP-2026)**: Painel inteligente de internações hospitalares do SUS (Challenge FIAP em parceria com a Oracle). Pipeline ETL com ~4,5 milhões de internações reais, Oracle 23ai com esquema estrela, Materialized Views, OCI e IA conversacional local.
2. **[Barbearia Espiral ✂️](https://github.com/mateus-henriquee/agendamento-barbearia)**: Sistema de agendamento online com Pix e WhatsApp, feito com Next.js, TypeScript, PostgreSQL e Docker. Zero overbooking garantido pelo banco de dados, validado com teste de concorrência.
3. **[Python 🐍](https://github.com/mateus-henriquee/python)**: Meu repositório focado especificamente em projetos Python desenvolvidos por mim.
4. **[CRUD Python x MongoDB 🍃](https://github.com/mateus-henriquee/crud-pythonXmongo)**: CRUD em Python com PyMongo e MongoDB.
